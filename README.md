# Agent Index comments

Comment threads for the agent pages on [aiworthusing.com/agent-index](https://aiworthusing.com/agent-index/).

There is no code here. This repository exists so the comments have a home:
each agent page's thread is a **GitHub Discussion** in this repo, rendered on
the page by [giscus](https://giscus.app).

- One discussion per agent, titled `agent:<slug>` — e.g. `agent:life` is the
  thread under <https://aiworthusing.com/agent-index/life>.
- A thread is created the first time somebody comments on that agent's page.
- Comment here or comment there; it is the same thread either way.
- You own what you write. Edit or delete your own comments any time.

Moderation is GitHub's: hide, delete, lock, report or block, from the
discussion itself.

The widget lives in `agent-index/index.html` of the (internal) aiworthusing
repo, themed by `agent-index/giscus-theme.css`.
